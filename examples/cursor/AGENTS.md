# Weavz MCP with Cursor project guidance

Use the configured Weavz MCP server for apps connected to the workspace selected through OAuth. Discover the relevant tool and alias first; retrieve only what is needed. Never ask for pasted API keys, MCP bearer tokens, OAuth tokens, or connected-app passwords. Before external writes or destructive changes, identify the target and proposed change and wait for approval.

MCP setup is client configuration, not this instruction file. Preserve unrelated MCP servers and global settings. Do not commit credentials. Keep verification claims limited to the checks actually run.
