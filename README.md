# Weavz MCP examples

Connect agent frameworks and AI clients to the apps people already use through Weavz MCP.

Tool Mode exposes selected app actions as individual tools. Code Mode exposes discovery, API inspection, and JavaScript composition through a compact MCP surface. Choose the server mode that fits the task.

- [Weavz](https://weavz.io)
- [Tool Mode](https://weavz.io/docs/guides/mcp-tool-mode)
- [Code Mode](https://weavz.io/docs/guides/mcp-code-mode)
- [Connect your AI client](https://weavz.io/docs/guides/weavz-mcp-app)
